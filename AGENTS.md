# RuangTerra (LMS)

RuangTerra adalah platform Learning Management System (LMS) berbasis web untuk memfasilitasi kegiatan belajar mengajar, pengelolaan materi, tugas, bank soal, dan kuis secara interaktif dan terintegrasi.

> **Instruksi:** Seluruh dokumentasi konteks proyek ada di folder `context/`. Baca `context/rules.md` WAJIB sebelum melakukan coding apapun.

## Panduan File Dokumentasi (`context/`)
- `context/rules.md` — wajib dibaca setiap sesi, sebelum coding
- `context/PRD.md` — baca per-section sesuai kebutuhan task, JANGAN baca seluruh file kecuali diminta eksplisit
- `context/CHANGELOG.md` — baca 3-5 entri terakhir untuk konteks kerja terbaru
- `context/CHANGELOG-archive.md` — JANGAN dibaca kecuali diminta eksplisit (riwayat lama, bukan untuk kerja aktif)
- `context/SCHEMA.md` — sumber kebenaran struktur database saat ini, rujuk ini bukan §4 PRD untuk detail skema teknis
